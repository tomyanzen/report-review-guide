# 画像診断レポート 判定ガイド

画像診断レポート遡及的確認プロジェクトのレビュワー向け A・B判定ガイドです。
スマートフォンで開いて、設問に答えると判定と次にすることが表示されます。

**公開URL**: https://tomyanzen.github.io/report-review-guide/

## これは何か

配布リストに記載された症例について、画像診断レポートで指摘された所見に「適切な対応」がとられているかを判定するための手順を、そのまま画面にしたものです。

判定フローは配布の「判定チェックシート（レビュワー用）」に準拠しています。

- Q1 「思わぬ異常所見」の記載があるか
- Q2 その所見は診療の中で認識されていたか
- Q2-1 死亡例で、当該所見が死因と明らかに無関係か
- Q3 所見に対して対応がなされているか
- Q4 所見への対応が不要と判断できるか

各設問には用語の解説がつき、B判定のときは備考欄に書く文の候補が表示されます。

## 患者情報について

このページに入力欄はありません。患者情報を入力する箇所はなく、操作内容はブラウザにも外部にも一切保存・送信されません。設問に答えるだけの静的なページです。

## 正式な手順について

正式な手順は配布の「判定チェックシート（レビュワー用）」が基準です。本ページはその判定フローを画面化した補助ツールです。
